# Know Your Labels

A mobile-friendly Inclusive Health nutrition-label trivia game created for Big Day of Play.

## What players can do

- Choose a 5-question, 10-question, or full round
- Select Rookie, Detective, Ninja, or mixed difficulty
- Turn on an optional 20-second timer
- Read Nutrition Facts-style labels for familiar foods
- Earn points and streak bonuses
- Receive an explanation after every answer
- Play with touch, mouse, or keyboard controls

The current question bank contains 18 educational questions covering serving sizes, calories, sodium, fiber, protein, total sugar, added sugar, and percent Daily Value.

## Files

- `index.html` — game interface
- `styles.css` — responsive Inclusive Health-inspired styling
- `questions.js` — editable question bank
- `app.js` — gameplay, scoring, timer, and results
- `.nojekyll` — tells GitHub Pages to serve the files as a plain static site
